# Light pulse sound

`light-pulse.mp3` is Josh W. Comeau's `enable-sound.mp3`, used by the speaker / enable-sounds control on his website. It plays once when a visitor sends a light pulse, at volume 0.4. The Sound checkbox remembers the visitor's preference when browser storage is available.

Source: https://github.com/joshwcomeau/use-sound/blob/main/stories/sounds/enable-sound.mp3

Article and inspiration: https://www.joshwcomeau.com/react/announcing-use-sound-react-hook/

The upstream repository's MIT license is included in LICENSE.txt. The original audio is unmodified and served locally. Playback uses the browser's native audio element; React and use-sound are not required by this Astro site.
